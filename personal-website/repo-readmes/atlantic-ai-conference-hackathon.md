# HealthByte

## What

A hackathon experiment in simulated reader reactions to healthcare articles and revisions based on that feedback.

## Why

We explored how to inspect audience reactions before changing public-facing information. Simulated responses are not evidence of real-world persuasion or clinical benefit.

## Demo

[Historical dashboard](https://healthbyte-dashboard.vercel.app/); current availability is not verified.

## Run it

The inspected upstream README does not establish a reproducible setup command. Dependencies, configuration and an entrypoint must be verified before publication.

## How it's tested

An automated test invocation is unverified. Iterative persona scoring is part of the experiment, not a substitute for validation with people.

## How it works

One agent simulates a reader; another revises an article using the response. I contributed as part of the hackathon team, rather than claiming sole ownership.
