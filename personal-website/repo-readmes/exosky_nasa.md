# Sky Painters

## What

An educational sky explorer with exoplanet viewpoints and constellation drawing.

## Why

We built an interactive way to explore how the night sky changes with the observer's position.

## How it works

React and Three.js render a sky derived from Gaia and NASA Exoplanet Archive data, with a Python and PostgreSQL backend. I am listed among the hackathon contributors; individual implementation ownership is not established here.
